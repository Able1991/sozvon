Документация

Установка

  1. Скачай Sozvon.dmg и перетащи Sozvon в «Программы». Приложение подписано и нотаризовано Apple.
  2. Запусти и пройди мастер: имя, языки звонков, модель, помощник для саммари. Движок поставится сам за 5-10 минут.
  3. Разреши «Микрофон» и «Запись экрана и системного аудио». Видео не записывается.

Claude Code и Codex

Настройки → Claude и Codex → Подключить. Или вручную:

claude mcp add --scope user --transport http sozvon http://127.0.0.1:47816/mcp
codex mcp add sozvon --url http://127.0.0.1:47816/mcp

Инструменты: list_calls, get_call, search_calls, transcribe, list_profiles, add_terms, add_replacement. Сервер работает, пока запущен Sozvon.

Вопросы

Нужен ли интернет во время звонка?

Нет. Запись и расшифровка работают офлайн. Интернет нужен только для установки и, по желанию, для саммари.

Собеседник узнает, что я записываю?

Sozvon не подключается к звонку, он пишет звук на твоём Mac. Предупреждать собеседников о записи твоя ответственность: в разных странах свои правила.

Почему не Intel?

Распознавание работает на MLX, а он есть только на Apple Silicon.

Mac тормозит во время расшифровки

Включи «Настройки → Распознавание → Не мешать работе»: расшифровка будет уступать другим программам.
